# BW Elite Goalkeeping — website mockup

A responsive, multi-page design concept using original imagery from https://www.bwgoalkeeping.co.uk/.

## Review locally

Download the repository ZIP, extract it, then open `index.html` in a browser. No installation or build step is needed. A local server can also be started with `python3 -m http.server 8000`.

## Preview hosting

This is a buildless static website. For Cloudflare Pages select **no framework**, leave the build command empty, and use `/` as the output directory. Connect this mockup repository and use a separate preview address. Do not change the existing business domain.

## Included

- Responsive homepage and supporting pages
- Original branding and local, optimised imagery
- Mobile navigation, booking placeholder dialog and preview-only enquiry form
- Source archive in `archive/source-reference.zip`, image provenance in `archive/inventory.json` and page mapping in `page-index.csv`; see `REVIEW.md` for launch checks

Booking is intentionally a placeholder. No messages are sent. This is a design review, not a production migration.
